# Solutec — Soluciones que conectan

Sitio web corporativo de **Solutec**, con identidad visual Opción 4 (*Hub*) del branding original y portafolio de los sistemas desarrollados.

## Ver el sitio

Abrí `index.html` en un navegador, o levantá un servidor local:

```bash
python -m http.server 8080
```

Luego entrá a `http://localhost:8080`.

## Estructura

| Archivo | Contenido |
|---|---|
| `index.html` | Estructura y secciones del sitio |
| `styles.css` | Diseño responsive, paleta y tipografías |
| `script.js` | Menú móvil, filtros, animaciones y formulario |
| `data.js` | Proyectos del portafolio (editar aquí) |
| `assets/logo-hub.svg` | Símbolo Hub recreado en SVG |
| `BRAND.md` | Tokens de marca y decisión de identidad |

## Cambiar los datos de contacto

Los datos actuales son **de ejemplo** (`hola@solutec.com.ar`, `+54 11 5555-0142`, etc.). Reemplazarlos en `index.html` dentro de la sección `#contacto` y el footer.
